ETAPA C — REDES Y ANIMACIÓN DE GRAFOS NEURONALES
==============================================

1. ABRIR el ZIP, entrar hasta ver src/, docs/, tests/, notebooks/, scripts/.
2. COPIAR ESAS CARPETAS (y no la carpeta completa Etapa_C) a:
      K:\Repositorios\Proyecto-COPTI\
3. ACEPTAR combinar carpetas.
4. REEMPLAZAR SOLO src/FitzHughNagumoControl.jl (versión actualizada A+B+C).
5. NO reemplazar Project.toml, Manifest.toml ni archivos previos.

En la terminal de VS Code ubicada en la raíz (NO en julia>):

    julia --project=. tests/runtests.jl
    julia --project=. tests/test_stage_B.jl
    julia --project=. tests/test_stage_C.jl
    julia --project=. scripts/run_stage_C.jl

Para video MP4 (opcional, codificación más lenta):

    julia --project=. scripts/run_stage_C.jl --video

Notebook: notebooks/03_networks.ipynb (kernel Julia con proyecto activo).

No hay paquetes nuevos que instalar si las etapas A/B ya están funcionales.
Si hay error, copiar el texto exacto de la terminal para depuración.
